# Abu P0 Animation Batch 1 (Stage 0 Baby)

Includes looping animation frames: idle (6 frames @6 FPS), walk (6 frames @8 FPS), happy (4 frames @8 FPS).

All frames are 384x384 RGBA, transparent, facing right, aligned to baseline Y=361, and use nearest-neighbor scaling. These are a visual prototype batch, not yet final QA production art: walk-cycle consistency and true transparency edge cleanup should be reviewed, and marker images are not included.

Import per-frame PNGs as image sequences. Loop idle/walk/happy as indicated in manifest.
